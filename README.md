# Révisions Histoire 5e — Chrétientés et Islam (Chapitre 2)

Application web minimaliste de révision pour le chapitre 2 du thème 1 d'Histoire en 5e :
**« De la naissance de l'islam à la prise de Bagdad par les Mongols : pouvoirs, sociétés, cultures (VIIe-XIIIe siècles) »**.

## Accès pour les élèves

Le site est en ligne à l'adresse :

👉 **https://ainhoajosseran-gif.github.io/revisions-histoire-5e/**

Aucun compte, aucune installation : le lien s'ouvre sur ordinateur, tablette ou téléphone, et fonctionne hors ligne après la première visite (les réponses restent sur l'appareil de l'élève, aucune donnée n'est envoyée).

## Les 5 modes de révision

| Mode | Contenu |
|---|---|
| 📖 Les fiches | Les 6 fiches du chapitre : naissance de l'islam, sunnites/chiites, le calife et le gouvernement de l'empire, les califats rivaux, la civilisation urbaine et Bagdad, croisades / Reconquista / échanges |
| 🗂️ Flashcards | 23 notions du glossaire (Hégire, calife, vizir, émir, cadis, djihad, sultan, Maison de la sagesse…), cartes retournables et filtrables par partie du chapitre |
| ✅ QCM | 25 questions avec explication après chaque réponse et bilan final des notions à revoir |
| ⏳ Chronologie | 13 étapes clés (622 → 1492) à replacer dans l'ordre, avec frise corrigée |
| 🏛️ Les califats | Le tableau des califats à compléter (capitales, dates, branche, territoires) avec vérification et corrigé |

## Technique

- Un seul fichier autonome : `index.html` (HTML + CSS + JavaScript, sans dépendance externe ni serveur).
- Contenu issu de la leçon du chapitre (document de travail du professeur).
- Hébergement : GitHub Pages, source = branche `main`, dossier racine.
